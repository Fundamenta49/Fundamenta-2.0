# Fundamenta 2.0

A comprehensive life skills learning platform powered by AI, designed to help users develop essential skills for personal and professional growth.

## Features

- 🤖 AI-Powered Learning
  - Personalized learning paths
  - Interactive AI tutors
  - Real-time feedback and guidance

- 📚 Comprehensive Learning Modules
  - Financial literacy
  - Career development
  - Nutrition and health
  - Personal development

- 🎯 Interactive Learning Experience
  - Progress tracking
  - Skill assessments
  - Achievement system

## Tech Stack

- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express
- AI: OpenAI, Hugging Face
- APIs: YouTube, FRED, Nutritionix, Spoonacular, USDA, Adzuna
- Database: PostgreSQL

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Copy `.env.example` to `.env` and fill in your API keys
4. Start the development server:
   ```bash
   npm run dev
   ```

## Environment Variables

See `.env.example` for required environment variables. You'll need to obtain API keys for:
- OpenAI
- Hugging Face
- YouTube
- FRED
- Nutritionix
- Spoonacular
- USDA
- Adzuna

## Development

- `npm run dev`: Start development server
- `npm run build`: Build for production
- `npm run test`: Run tests
- `npm run lint`: Run linter
